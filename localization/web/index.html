连接应用

任何支持 SOCKS5 或 HTTP 代理的应用都可以使用本代理，例如 v2rayN、v2rayNG、NekoBox、浏览器和 Telegram 等。它们访问任何网站的流量都会经过 Mozilla 的 VPN 服务器，并不限于访问 Mozilla 网站。同一地址同时支持 SOCKS5 和 HTTP 代理客户端。

SOCKS5 地址127.0.0.1:10810
适用于 v2rayN、v2rayNG、NekoBox 的链接socks://Og@127.0.0.1:10810
  • v2rayN、v2rayNG、NekoBox：复制链接后从剪贴板导入，或使用上述地址添加 SOCKS 服务器。
  • 在手机等其他设备上使用：在设置中将 SOCKS5 监听地址设为 0.0.0.0:10810 ，并设置 SOCKS5 用户名和密码，然后使用本机的网络地址代替 127.0.0.1。

TCP：端口 80、443、8080 和 8443

Mozilla 的代理仅允许连接以下网页端口： 80、443、8080 和 8443 。Mozilla 服务器会拒绝其他所有端口，例如 http://203.0.113.5:9898/、SSH（22）或邮件服务（25、465、587、993）。本程序无法改变这一限制，但有两种例外：通过 SSH 连接 GitHub 的 git 请求会自动改用 GitHub SSH 服务器的 443 端口；发送到代理的 DNS（53）请求则由本程序通过 Mozilla 使用 DNS over HTTPS 解析并响应。

  • 将您自己的网站部署在上述四个端口之一（通常选择 8080 或 8443）。
  • 或让浏览器直接访问该地址：Firefox → 设置 → 网络设置 → 不使用代理的地址。

UDP：端口 80、443、3478、8080、8443 和 49152-65534

其他 UDP 端口的通话和在线游戏无法通过此代理使用。在 VPN 中，QUIC（UDP 443 端口）会被有意拒绝：浏览器会改用基于 TCP 的 HTTP/2。

本程序的连接被转回自身（代理回环）

其他程序将本程序自身的流量又转入本代理，导致无法连接 Mozilla，所有连接都失败。在路由器的 PassWall2 中，请关闭本机代理（Localhost Proxy）。若使用其他 VPN 程序的 TUN 模式（v2rayN、Clash、sing-box），请添加进程规则，让 arman-vpn-core 直连。

本国或本地区网站直连（分流）

可在“设置 → 分流”中按需启用。所选地区（默认为伊朗，也支持中国、俄罗斯、阿富汗、土耳其、印度尼西亚和巴西）的网站和网段将通过您自己的网络直连：访问更快，不会因境外 IP 地址而遭到拒绝，也不消耗账号的流量额度；其他流量仍通过 Mozilla。域名和网段列表每 10 天自动下载更新。直连网站可以看到您的真实 IP 地址。
